# Design References Directory

Please place your three supplied Figma design screenshot images here (e.g., `design1.png`, `design2.png`, `design3.png`).

The application UI is engineered to match your Figma visual direction:
- **Primary Color Palette:** Vibrant campus green (`#16a34a`, `#15803d`, `#22c55e`), crisp white cards (`#ffffff`), modern neutral dark text and borders (`#0f172a`, `#334155`, `#e2e8f0`).
- **Typography:** Modern clean sans-serif (Inter / Outfit / system UI), clear visual weight.
- **Components:** Rounded cards (`border-radius: 12px - 16px`), subtle elevation shadows, pill-shaped status badges, accessible touch targets (min 44px on mobile), responsive mobile bottom bar and desktop sidebar/header navigation.
- **Screens:**
  1. Landing Page (Find Your Perfect Study Spot, Get Started, Feature Highlights)
  2. Campus Dashboard & Interactive Map
  3. Quiet Spots List with dynamic filters (All, Quiet, Moderate, Noisy, Unknown/Stale)
  4. Location Details with historical reading charts and navigation action
  5. Live Noise Monitoring with Web Audio API waveform visualization and contribution toggle
  6. Algorithm Performance Lab (Quadtree vs Linear Search benchmark)
  7. Login & Registration
  8. Privacy & Settings
